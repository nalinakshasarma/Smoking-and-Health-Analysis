# Smoking & Health Analysis Dashboard (Power BI)

## Project Overview
This project analyzes smoking patterns, patient demographics, and their relationship with various health conditions using Power BI. The interactive dashboard provides insights into smoking prevalence, smoking intensity, age distribution, diagnosed ailments, and affected organs.

## Objectives
- Analyze smoking status distribution among patients.
- Examine smoking patterns across different age groups.
- Evaluate smoking intensity based on average cigarettes consumed per day.
- Analyze the distribution of diagnosed health conditions.
- Explore the relationship between smoking exposure and health conditions.
- Identify the most affected organs based on recorded health cases.

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Data Visualization

## Key Findings
- Current smokers account for 30.15% of the patient population, while former smokers represent 27.22% and never smokers account for 42.63%.
- Smoking prevalence increases with age, reaching its highest level in the 60+ age group.
- Current smokers consume an average of 17.11 cigarettes per day.
- COPD and Reduced Lung Function are among the most prevalent diagnosed ailments.
- Lungs and Heart account for the highest number of recorded health cases.
- Average cholesterol levels remain relatively consistent across blood pressure risk categories.
